# Rock, Paper, Scissors

A command-line Rock, Paper, Scissors game written in Java where you play against a randomized computer opponent until you enter `quit`.

## Features
- Validates and normalizes user input (`rock`, `paper`, `scissors`, `quit`)
- Randomizes computer moves using `java.util.Random`
- Tracks wins, losses, and ties across rounds and displays a final score summary

## How to Run
```bash
javac RockPaperScissors.java
java RockPaperScissors
